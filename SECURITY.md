# Reporting a security issue

On the repository's **Security** tab, use **Report a vulnerability** if private reporting is available. Include the affected version, operating system and a minimal reproduction with invented files or dummy credentials. If the button is unavailable, open an issue asking the maintainer to enable private reporting. Share the technical details once the private channel is available.

Deepmine works with local AI usage, conversation records and files. Keep chat logs, screenshots of real conversations, ingestion keys, API credentials and save folders on your computer. The launcher’s `--diagnostics` option produces a small report suitable for discussing setup and connection problems. [Using the diagnostic report](CONTRIBUTING.md)

## 安全问题反馈

请优先从仓库 **Security** 页私下报告。如果私下报告入口没有开放，可以先在普通 Issue 中请维护者开启。复现材料使用虚构项目和占位凭据即可。
