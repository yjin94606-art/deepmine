# 深矿 1.0 · 一个人的作品矿坑

一张插画、一段铃声、一份工作簿，做完以后常常散在三个文件夹里。深矿把所选项目的创作记录排成一条向下的像素矿道。钻机沿着日期前进，做过的作品留在它们出土的那一层。

## 一次游玩

1. 在欢迎页试挖随包示例，或选择自己的本地项目。选项目后，深矿读取可用的 Codex、Claude Code、Git 与作品文件记录。
2. 点 **开挖**。已记录的用量和产出决定可挖深度。重复打开同一份记录会接着之前的进度走。
3. 钻到作品时钻机会停下。可以看原画的像素预览、试听支持的录音或展开作品来历。点 **继续** 才会恢复开凿。
4. 下次回来，沿矿道向上翻。悬停或轻点作品就能查看，已经挖过的墙段也可以重新布置。个人测绘簿保存当天的主动进尺与测绘章。

## 记录的依据

| 游戏里看到的东西 | 来自哪里 |
| --- | --- |
| 当日 Token | 已连接工具、API 或导入文件实际报告的用量。缺少数据时显示未知 |
| 矿壁上的作品 | 当前项目中观察到的文件、提交和已保存的作品版本 |
| 一段创作经过 | 能对应到这件作品的记录。可选 AI 小记取材于获准使用的内容 |
| 岩层里的灯、碎屑与矿车 | 游戏场景和陈设 |

矿坑存档保存在用户目录中。试玩可以直接打开。收藏 GitHub 藏宝图、读取在线资讯或开启 AI 小记时才会用到对应的外部服务。
