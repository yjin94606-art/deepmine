# 向下钻进：像素美术规格

本轮场景只围绕一台朝下的钻机、持续延伸的竖井与向下跟随的镜头构筑。绘图由原创 Canvas 像素簇组成，不使用生成图片或商业游戏素材。下面区分参考资料的原则与本项目自行确定的尺寸。

## 五个一手参考

1. [cure — The Pixel Art Tutorial，PixelJoint](https://pixeljoint.com/forum/printer_friendly_posts.asp?TID=11299)：强调可控像素簇，解释孤立噪点、平行色带、明暗阶梯与色相偏移。这里采用连贯色块和共享色阶，避免给每块石头描一圈亮暗边。
2. [Pedro Medeiros / Saint11 — Cluster Sketching and Painting](https://saint11.art/pixel_art_articles/article2/)：从大色块开始，再细化轮廓；远景、主体、前景分别建立；不规则的轮廓台阶需要清理。这里先验收钻机剪影和岩壁大切面，再加履带、接缝、反光。
3. [Derek Yu — Pixel Art Tutorial: Basics](https://derekyu.com/makegames/pixelart.html)：用稳定的像素线段表达轮廓；明暗负责塑造体积，细节不能遮掉体块；限定调色板。这里用上方驾驶舱、双侧竖履带、下方钻头建立第一眼可读的方向。
4. [Aseprite 官方 — Tiled Mode](https://aseprite.org/docs/tiled-mode/)：提供重复平铺的观察方式。这里对应生成混合变体的 3×3 预览，检查接缝、十字交界与重复图案，而非只检查单块好不好看。
5. [Itay Keren — Scroll Back，GDC 原始讲稿](https://media.gdcvault.com/gdc2015/presentations/Keren_Itay_ScrollBack.pdf)：讨论 camera-window、缓动和推进方向前视；第39页说明沿主要前进方向留出额外空间，第36页展示480×270游戏画面的案例。这里把前视方向改为下方，避免把钻机挤到画面底部。

## 本项目的构图与镜头参数

- 桌面建议逻辑画面 **480×270**；原始精灵按整数像素绘制，整幅画面统一最近邻放大。优先整数倍率；尺寸不足时改变可见世界范围或留边，不能单独拉伸机器。关闭图像平滑，并在最终绘制阶段统一取整相机坐标。
- 在扣除 HUD 遮挡后的游戏可视范围内，钻机中心保持约 **40%–45% 高度**。钻头下方至少留下约三分之一可视空间，展示接触面和即将进入的地层。70%高度的旧机位会压掉向下前视空间。
- 上段是已挖通的竖井、木撑和缆线；中段是黄色钻机与钻头接触面；下段是连续未开挖岩层。两侧支洞应短而疏，不能把画面变成横向小屋街景。
- 机器世界坐标向下增加，镜头跟随同一坐标；地形上移和新切开的岩层必须对齐。不能只在固定车辆后面循环背景。镜头平滑不能改变精灵尺寸或让两层取整方式不同。
- 远景用低对比冷色大面，中景岩壁保留三档明暗，近景仅在两侧用少量暗轮廓框住矿道。最高明暗反差与暖色集中于驾驶舱、黄色肩体和钻头；背景亮点不得均匀铺满。
- 真实深度与发现记录由游戏核心传入。环境石英属于装饰；带交互的矿样只来自记录。到达已知进度后可待机，不能用视觉循环制造新的工作成果。

## 原创素材合同

文件：`dist/drill-art.js`。浏览器导出 `window.DrillArt`，CommonJS 导出同一个 API。坐标均为逻辑像素。

| API | 锚点与范围 |
| --- | --- |
| `drawRig(ctx,x,y,frame=0,working=false)` | 中心锚点；36×47；范围x−18…x+17、y−23…y+23。最下端钻尖为y+23。 |
| `drawTile(ctx,x,y,biome=0,variant=0)` | 左上锚点；32×32；4地层×4变体。 |
| `drawCrystal(ctx,x,y,kind,frame=0)` | 底部中心；14×18；x−7…x+6、y−17…y。 |
| `drawSupport(ctx,x,y,width)` | 左上锚点；宽度按参数，高16像素，最小宽12。 |
| `drawLamp(ctx,x,y,on=true)` | 灯芯锚点；9×13；x−4…x+4、y−7…y+5。 |

地层依次为暖赭土、冷青岩、紫页岩、深蓝基岩。每张32×32地块最多使用本层三色，**超过93%保持安静底色**。v0.7中变体0是纯底色，变体2仅有一道轻痕，变体1/3各有一道浅断口，避免每个格子都出现同等大小的重复纹样。四边均为底色，任意变体相邻不会露出格线。场景可在不对齐网格的位置叠加`drawSeam`，形成自然错位地层。真正的深阴影由场景在井壁开挖交界处绘制；不能把每张地块画成高对比迷彩。主光来自左上，不应随机镜像整块素材。

矿样：`code`翡翠、`document`琥珀、`asset`紫晶、`other`蓝晶。三个相连晶柱中一个主柱最高，亮面细而集中，四帧只移动少量闪点。

## 色彩与动画约束

`DrillArt.palette`包含 **38个唯一不透明色**：共享轮廓/金属/最高光4色，四地层各3色，机身4色，驾驶舱3色，木材3色，四矿样各3色。完整十六进制值以代码中的冻结对象为准。v0.5的藏品与环境库在这些颜色上扩展到59色，详见下节；渲染器应优先复用色板。

岩层低饱和，三色明度差大幅收窄，暗面轻微向冷灰偏，亮面轻微向暖灰偏；仅用稀疏断口说明材质。黄色只集中在机器，最亮奶油色留给灯芯和少量金属反光。灯光采用固定色阶，不能靠全屏模糊、透明渐变制造大量中间色。

钻机四帧改变螺旋钻头的亮暗斜带、短竖履带和指示灯，外轮廓与锚点不变；休眠只用第0帧。颗粒、相机位移和凿开地形由场景渲染器负责。常用素材预绘到离屏图集，每帧直接拷贝。

## 验收

- 1倍尺寸、灰度和纯剪影下，都能立即读出“上舱、侧履带、向下钻尖”。
- 3×3混合地块没有格子边框或突然断掉的接缝；不靠更多噪点掩盖重复。
- 彩色焦点是机器，矿石次之；岩壁纹理不能抢过主体。
- 已完成程序验证：38唯一色、全部锚点边界、4个不同工作帧、稳定休眠帧、16个不同且最多三色的地块、四边与跨变体边缘一致、图集与直接绘制逐像素一致。最终构图仍需场景整合后的浏览器截图验收。

## v0.5：藏品、矿层内容与工坊

新增文件`dist/expedition-art.js`，UMD导出`window.ExpeditionArt`及CommonJS同名API。继续使用原创手写像素簇，不改变`DrillArt`机器。所有形状通过整数矩形与逐行扫描的像素多边形绘制；圆形齿轮也由整行像素构成，不产生抗锯齿中间色。

固定`palette`扩展为 **59个唯一不透明色**，保留原有色系，补入铜、苔藓、水体、纸张、化石和少量暖红。藏品拥有集中的亮面；环境以大体块、暗壳与局部亮物形成层次，不在背景铺高频碎点。四个矿层的环境只表示风貌，矿脉与藏品是否存在、是否可领取仍由真实记录与场景状态决定。

| API | 精确画布与锚点合同 |
| --- | --- |
| `drawArtifact(ctx,x,y,recipeId,variant=0,frame=0,assembled=true)` | 底部中心，56×64；边界x−28…x+27、y−63…y。不同造型在此透明画布内留白。 |
| `drawWorkshop(ctx,x,y,recipeId,variant=0,frame=0,assembled=true)` | 底部中心，88×76；边界x−44…x+43、y−75…y。已含木展台、实物或零件、施工架；场景不用重复绘制底板。 |
| `drawEnvironment(ctx,biome,x,y,variant=0,frame=0)` | 底部中心，96×88；边界x−48…x+47、y−87…y。`biome`使用`roots/aquifer/crystal/ruins`；同时兼容0…3。 |
| `drawVein(ctx,x,y,kind,richness=1,revealed=false,frame=0)` | 底部中心，32×24；边界x−16…x+15、y−23…y。`richness`取1…3；未揭露时保留岩盖与较暗晶面。 |

环境有2个变体、最多4帧。v0.6起藏品与工坊的`variant`支持0…2，模3处理；环境仍模2，`frame`仍模4，非有限数值归零。`assembled=false`显示对应配方的拆件，不把完整藏品用半透明覆盖来充当制作过程。浏览器按素材、变体、帧和组装状态缓存离屏精灵；没有Canvas离屏功能时使用相同整数绘制路径。缓存拷贝关闭图像平滑，随后恢复调用方状态。动画调度与减弱动态设置由场景负责。

八种配方的剪影和结构明确不同：

| recipeId | 实物结构 |
| --- | --- |
| `engine` | 双缸铜芯引擎：散热栅、铜管、飞轮和嵌入式发光核心。 |

| `compass` | 蓝钢罗盘：圆盘、阶梯圆框、南北双色指针和四向刻度。 |
| `rover` | 测绘机器人：轮组、机械臂、双目面板、伸缩测绘镜头和天线。 |
| `drill` | 萤石钻头：铜制轴座、齿轮、荧绿色与紫色交叠的向下螺旋切面。 |

矿层环境各两种布局：`roots`以弯曲树根、苔藓、蘑菇和嵌岩肋骨化石构成；`aquifer`以岩台瀑布、水池与小型发光鱼构成；`crystal`以暗岩壳和巨型紫青晶柱构成晶洞；`ruins`以旧齿轮、断轨、锈管和失效设备构成。布局变体改变重心与部件安排，避免沿纵井连续重复同一张背景贴图。

矿脉由岩壳、2至4块不同大小晶体和少量嵌岩颗粒组成。`code`为翡翠，`document`为琥珀，`asset`为紫晶，`other`为蓝晶；兼容`emerald/copper/crystal`材质别名。环境晶洞不自带可收集标记；真实节点的交互与证据由场景统一提供。

## v0.7：场景尺度、自然点缀与钻进动感

56×64的藏品继续供图鉴与详情使用。场景改用专门重画的32×32紧凑藏品，保留16种物品的独立剪影，不把大精灵半采样后直接缩小。场景资产不再普遍带有展示用木平台；最多绘制2至3像素高的冷色接地阴影。黄铜钻机仍为36×47，体量和明暗焦点高于单件场景物品。

`ExpeditionArt`新增三个可选接口，保留原有全部接口，色板仍为59色：

| API | 锚点、尺寸及用途 |
| --- | --- |
| `drawDressing(ctx,biome,x,y,variant=0,frame=0)` | 底部中心32×32；x−16…x+15、y−31…y。每层6种小景物，`variant`模6。 |
| `drawSeam(ctx,biome,x,y,variant=0,frame=0)` | 底部中心24×12；x−12…x+11、y−11…y。每层4种自然浅裂纹，`variant`模4；静态、无收益、无交互。 |
| `drawRelic(ctx,x,y,recipeId,variant=0,frame=0,assembled=true)` | 底部中心32×32；x−16…x+15、y−31…y。16种原生紧凑藏品；`assembled=false`以中性冷色岩壳遮住下部，表示未完全开凿的实物。 |

`biome`继续接受`roots/aquifer/crystal/ruins`及0…3。小景物的变体索引约定如下，便于场景有意识地配搭：

| 矿层 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| `roots` | 根须 | 苔藓垫 | 小蘑菇 | 破陶罐 | 肋骨化石 | 蕨叶 |
| `aquifer` | 滴水与浅洼 | 池岸 | 盐晶 | 小螺 | 水边芦苇 | 石笋 |
| `crystal` | 晶芽 | 嵌墙碎簇 | 紫苔 | 倒伏晶片 | 小晶洞 | 立方萤石 |
| `ruins` | 断管 | 旧灯 | 工具箱 | 齿轮碎片 | 残轨 | 压力表 |

小景物以大块暗形和少量中间色说明材质，高亮集中在灯芯、水滴和一两处晶面。自然矿纹只在地层三色附近变化，不把装饰画成可领取矿石。场景负责避开主角和真实矿脉，把装饰疏密、朝向和嵌墙位置错开；完整96×88环境仅适合少量里程碑洞室，不应连续堆叠。

轻量缓存按离散变体生成。静态裂纹忽略帧号；只有滴水和旧灯的小景物生成动画帧，紧凑藏品仅机器人指示灯需要多帧，避免静物随着全局动画重复创建缓存。相机、碎裂、长距离尘土和飞入钻机的粒子仍由场景负责。

`DrillArt.drawRig`保持原接口与36×47范围，新增固定排气口、三段上升消散的像素烟气、钻头两侧递进排渣和一次小金属闪点。休眠稳定为第0帧；四个工作帧轮廓包围框不变，螺旋钻头与履带继续转动。烟气和碎渣不占用外部空间，因此不会破坏现有镜头/碰撞锚点。

已验证`ExpeditionArt` **1440种绘制组合**：边界、整数像素、59色色板、离屏/直接绘制一致；16种紧凑剪影互不相同，每层6种小景物都不同。`DrillArt`验证4个工作帧、稳定休眠、16种留白地块、四边无缝以及缓存一致。已实际查看`work/qa/scene-dressing.png`、`scene-seams.png`、`scene-relics.png`、`drill-rig-preview.png`与`drill-tiles-preview.png`。生成器为`render-scene-art.cjs`，检查脚本为`test-scene-art.cjs`和`test-drill-motion.cjs`（均位于`work/qa`）。
