# 回看一件 Codex 作品

在图片详情里选「上一稿」或「本稿」，再点「↓ 在矿坑里看」。镜头会回到那一稿出土的位置，岩壁展开对应原图的像素场景。另一稿有独立出土记录时，会定位到它自己的矿层。

沿井道向上翻阅时，在已挖出的图片或视频旁稍停，靠近视野中央的作品就会展开。继续滚动即可经过它，进入下一层。

音频和视频详情可以直接播放浏览器支持的原文件版本，当前预览上限为 16 MiB。作品有同名字幕、媒体内嵌描述，或同目录展示页明确介绍了它时，展开「从作品中读到的内容」可以核对线索和时长。展开「查看原始记录」可以查看对应来源。

如果 Codex 或 Claude Code 在最终答复里给了作品链接，深矿会把它与当轮、同路径的已记录版本核对。匹配时显示交付时间，开启本机对话摘录后还可看到该次交付对应的请求。这样可以分清「请做一支宣传片」和片中角色原本是怎样创作的。旧作品在重新同步时也会检查。

打开矿坑右上角的「来源」。这里会显示所选范围今天由 Codex 记录的 Token，以及有生成回执的作品版本数。多种工具同时接入时，Codex 的数字只取自它自己的计量。

点「回看这件作品」，镜头会沿已经挖过的那一段井道向下，到达作品所在的深度。随后可以查看作品小记和生成或修改时间。在设置里选择「结合作品和创作过程写」，小记还会讲到可以核对的创作细节。绘图工具确实引用了上一稿，且那份原图仍能按内容指纹读取时，详情卡可直接切换「上一稿」和「本稿」。展开来源时能看到小记取材于作品、AI 的设计说明，还是这件作品的创作对话。想核对当时的请求，可展开「查看原始记录」。回放保留实际矿坑深度和已领取的途中资讯。

出土时关掉标签页，同一天用同一浏览器和地址重开，会回到那件尚未点「继续」的作品。在另一个标签页点过「继续」，原标签页也会恢复掘进。

作品和用量各有自己的依据。工具成功写入文件，而且路径和这次写入的内容能核对上时，作品才归到 Codex 名下。只有用量、还没有可核对的已挖作品时，来源页仍然能显示用量。请求原话需要在本机启用对话记忆，并且这次操作确实留下了相应记录。

要在另一台电脑上回看自己的作品，打开那台电脑上的启动文件，选择对应的项目，再从右上角打开「来源」。[连接自己的项目](CONNECT-CODEX.md)

## 各类作品能看到哪些细节

| 作品 | 可核对的细节 |
| --- | --- |
| 图像 | 对应版本的原图、像素轮廓和配色。本机模型可以给出大致主题。人物姓名和具体改稿要求需要作品本身或创作记录提供依据。 |
| 文档、表格、演示稿 | 标题、正文、工作表名和列名，或演示稿的页标题。数值表可显示从数据中提取的走势。 |
| 程序、网页和数据 | 写入代码的函数、缩进、数值，以及网页中的可见文字和按钮。执行成果需另有运行记录。 |
| 声音、视频和模型 | 音频标签、章节、PCM WAV 波形、浏览器可解码的视频实帧，或立体模型中已命名的部件。 |

文件记录用内容指纹核对版本，Git 作品按提交读取。原文件被删除、文件超过预览上限或浏览器缺少解码能力时，仍可查看已经记录的时间和来源。图片预览上限为 8 MiB，完整 Office、OpenDocument、PDF 内容解析和视频抽帧上限为 16 MiB。PDF 支持部分可提取的首页文字，扫描件需另有文本。

换一台电脑或项目，矿坑会读取那里保存的作品版本。图像、视频帧、音频封面或文档中可读取的预览会保留原作的构图。表格柱子的高度依据实际数值，双盘录音机上的波形取自可读取的 PCM WAV。文档中明确写到白鹭、灯塔等已有的题材时，游戏会在本机画出对应的插画。

静态 SVG 可以按作品中的基本形状、路径和配色重绘。含有动画、外部资源或暂不支持的样式时，游戏会使用可读的作品线索或媒介图标。

## 岩壁展位

钻头越过作品后再前进 3、12、32 米，搁板、木撑和立柱会逐步修好。点开已出土的作品，在详情底部选「摆放到岩壁」，可以把它拖到另一侧或邻近高度，也可以用方向键移动，按 Esc 完成。位置按矿坑保存。

挑选具体版本后可以出售或移出矿道，原文件仍能在项目里找到。没有关联计量时基础价为 6 金币，有逐件用量回执时另加 `ceil(sqrt(Token / 100))`。在「设置 → 矿道工坊」用 6 金币安装黄铜矿灯，或用 14 金币给矿道铺青釉展台。其他版本继续陈列。

## 物品小记

「物品小记」默认关闭。开启后，出土或打开详情时，已登录的 Codex 可以按项目、作品版本和所选语言写一段介绍。对缺少配图且有具体题材的文档或对话记忆，它还可以根据内容新绘一幅像素插画。例如，同名的《观察手记》可以挖出文中描写的黄铜茶壶，也可以挖出另一份手记里的热气球。可读线索不足时，岩壁会留下代表作品类型的造型。

等候期间可以阅读本机介绍、继续开挖。路过岩壁上的作品只会显示本机已有的内容。「仅根据作品写」使用文件线索。「结合作品和创作过程写」还会使用可归到该版本的讨论。请求原话的保存由独立的对话记忆选项控制。[模型来源与主题表](../vision/README.md)
