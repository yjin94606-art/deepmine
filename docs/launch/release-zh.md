## 深矿 1.1.1 · 今天的 Token，挖出了什么？

**[网页试玩](https://yjin94606-art.github.io/deepmine/)** · **[下载 Windows x64 离线安装包](https://github.com/yjin94606-art/deepmine/releases/download/v1.1.1/deepmine-v1.1.1-windows-x64-setup.exe)** · [macOS / Linux](https://github.com/yjin94606-art/deepmine/releases/download/v1.1.1/deepmine-v1.1.1-source.zip)

第一铲挖出来的是一位温室植物学家。她围着黄围巾，刘海里别着一枚叶形发夹。创作小记里藏着一个细节。为了让那片叶子露出来，这一稿前后改了两次。

这是随包试玩里的虚构作品。换成自己的项目，岩层里就是你画过的图、剪过的声音、写过的东西。当天记录到的 AI 用量和产出给钻机增加可挖深度。岩石一裂，钻机停下来，把那一件作品交到你面前。明天再来看，它还在原来的位置。

**第一天可以试三件事**

- 在欢迎页点 **先试玩一次挖掘**。不用连接 AI 账号就能试手感。
- 选一个自己的 Codex、Claude Code 或 Git 项目。开挖、查看出土作品，然后沿矿道往回翻。
- 打开右下角档案箱里的 **个人测绘簿**，看看今天亲手挖了多远，拿到哪一枚测绘章。

**下载**　Windows x64 选 `deepmine-v1.1.1-windows-x64.zip`，解压后双击最外层的 **Open Deepmine.cmd**。macOS 和 Linux 选 `deepmine-v1.1.1-source.zip`，使用 Node.js 20 或更高版本。macOS 双击 **Open Deepmine.command**，Linux 运行 `sh open-deepmine.sh`。[打开 v1.1.1 下载页](https://github.com/yjin94606-art/deepmine/releases/tag/v1.1.1)

本次更新加入 Windows 离线一键安装、矿坑内切换项目和组合出土作品明细。打开两个浏览器或中途退出，钻头都会等你确认出土作品。

矿坑存在自己的电脑上。日常开挖无需账号或云服务器。AI 创作小记、对话摘录和在线资讯按需开启。
